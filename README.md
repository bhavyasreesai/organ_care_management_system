# 🫀 Organ Care Management System

## 📌 Project Overview

The **Organ Care Management System** is a full-stack web application developed to manage organ donation, transplantation, and related healthcare processes. It provides a centralized platform to handle donors, recipients, organs, hospitals, and other critical modules.

---

## 🚀 Features

* ✔ Full CRUD Operations (Create, Read, Update, Delete)
* ✔ 14 Integrated Modules:

  * Donor
  * Recipient
  * Organ
  * Hospital
  * Staff
  * Storage Location
  * Organ Testing
  * Organ Transport
  * Family Consent
  * Insurance
  * Transplant
  * Legal Documentation
  * Follow-Up
  * Alerts
* ✔ Interactive Dashboard with real-time data
* ✔ User-friendly UI with forms and tables
* ✔ Data validation and error handling
* ✔ REST API integration

---

## 🛠 Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Spring Boot (Java)
* **Database:** MySQL
* **ORM:** JPA (Hibernate)

---

## ⚙️ How to Run the Project

### Step 1: Start Backend

Open terminal in backend folder:

```bash
cd backend
.\mvnw.cmd spring-boot:run
```

Wait until:

```text
Tomcat started on port 8080
```

---

### Step 2: Verify Backend

Open browser:

```text
http://localhost:8080/api/donors
```

---

### Step 3: Run Frontend

* Open `index.html` from the frontend folder
* Use Chrome browser
* Press **Ctrl + F5** to refresh
